# Política de Privacidad de Call Panico

Última actualización: 27 de agosto de 2026

## 1. Introducción

Esta Política de Privacidad describe cómo Call Panico ("la aplicación", "nosotros" o "nuestro") trata la información cuando usted usa la aplicación móvil.

Call Panico es una aplicación de asistencia y alerta de emergencia por voz. Nuestro objetivo es ayudar al usuario a detectar una frase de emergencia y ejecutar acciones configuradas en el dispositivo.

## 2. Información que recopilamos

Call Panico no recopila información personal en nuestros servidores ni exige crear una cuenta.

La aplicación puede almacenar de forma local en el dispositivo:

- frase o frases de emergencia configuradas por el usuario
- contactos SOS configurados por el usuario
- estado de activación de la protección
- historial local de alertas generadas por la aplicación

Esta información se guarda en el dispositivo del usuario mediante almacenamiento local y no se envía a nuestros servidores.

## 3. Permisos que puede solicitar la aplicación

Según la función utilizada, la aplicación puede solicitar los siguientes permisos:

- Micrófono: para reconocer la frase de emergencia por voz.
- Contactos: para permitir importar o administrar contactos SOS, si el usuario usa esa función.
- SMS: para enviar mensajes de ayuda a los contactos configurados cuando el usuario activa una alerta.

La aplicación solo usa estos permisos para ofrecer sus funciones principales y no los utiliza para recopilar datos para otros fines.

## 4. Uso de Internet

La aplicación no requiere una API propia ni un servicio en la nube para su funcionamiento principal.

Sin embargo, pueden existir conexiones normales de la plataforma o de servicios de terceros del sistema operativo, por ejemplo:

- Google Play Services
- Google Play Console / Play Integrity / métricas de Google si el sistema o Play las habilita

Estas conexiones se rigen por las políticas de Google y no implican que Call Panico envíe información personal a nuestros servidores.

## 5. SMS y comunicación de emergencia

Si el usuario activa una alerta, la aplicación puede generar un mensaje de emergencia y enviarlo mediante la capacidad SMS del dispositivo a los contactos configurados o al número de emergencia definido en la app.

El envío de SMS se realiza desde el dispositivo del usuario y depende del proveedor móvil y de los permisos concedidos por el usuario.

## 6. Compartición de información

No vendemos, alquilamos ni compartimos información personal con terceros para fines comerciales.

La información configurada por el usuario permanece en el dispositivo, salvo que el propio usuario decida compartirla mediante funciones del sistema operativo o servicios de terceros.

## 7. Retención de datos

La información local se conserva mientras la aplicación permanezca instalada o hasta que el usuario la elimine desde la propia app o desde la configuración del dispositivo.

Si el usuario desinstala la aplicación, los datos locales almacenados por la app pueden eliminarse junto con ella, según el comportamiento del sistema operativo.

## 8. Seguridad

Tomamos medidas razonables para proteger la información almacenada localmente. Aun así, ningún sistema es completamente seguro. Recomendamos al usuario proteger su dispositivo con bloqueo de pantalla y mantener el sistema operativo actualizado.

## 9. Menores de edad

Call Panico no está dirigida específicamente a menores de edad. No recopilamos intencionalmente datos personales de menores.

Si un padre, madre o tutor considera que un menor nos proporcionó información, puede solicitar su eliminación siguiendo el contacto indicado abajo.

## 10. Cambios a esta política

Podemos actualizar esta Política de Privacidad ocasionalmente para reflejar cambios en la aplicación, en la normativa aplicable o en los servicios utilizados.

La versión actualizada se publicará en este mismo archivo con una nueva fecha de actualización.
